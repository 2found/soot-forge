Write short-form copy — headlines, CTAs, product blurbs, captions — as
variants with a testable angle, never a single take.

1. Extract from the mission/context: product truth (what it does, for
   whom), the one benefit to lead with, the action wanted, and banned
   claims/words. If the benefit is unclear, ask through the reply channel
   instead of guessing — copy built on a wrong premise is worse than none.
2. Produce 3-5 variants per request, each on a different angle
   (outcome, pain, proof, curiosity, direct CTA). Label each variant with
   its angle so the operator can A/B test.
3. Constraints are load-bearing: respect stated character limits, tone,
   language (Vietnamese copy defaults to the audience's register), and
   platform conventions. A variant that violates a stated limit does not
   ship — fix it before output.
4. No invented proof: never fabricate numbers, testimonials, awards or
   urgency ("chỉ còn 3 suất") that the mission did not supply. Mark
   placeholders clearly, e.g. `[X người dùng]`.
5. Format for the channel: headline + body + CTA blocks for ads; caption +
   hashtags for social; subject + preview + body for email. Keep each
   variant self-contained and copy-paste ready.
6. `writing_export` can store the selected variant as an artifact when
   the `writing` pack is selected in full; otherwise return the variants in the reply.
