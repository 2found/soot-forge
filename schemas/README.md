# Soot authoring schema

pack.json is the generated public soot/v1 pack schema exported by 2found/2agent. SOURCE.md records the baseline import revision.

The `resource_fields` extension is a coordinated, unreleased runtime/Pack change.
It was regenerated by `go run ./scripts/contractgen` in 2agent; use a runtime
containing that extension and record its release revision when publishing Forge.
Older strict runtimes reject Packs declaring this field.
Runtime semantic validation remains soot add/check. Refresh this file from Soot contract generation when the public contract changes; never hand-edit it. Forge ships the schema to keep PR validation public and independent of the private runtime repository.
